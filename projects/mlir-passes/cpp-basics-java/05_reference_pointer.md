# 05 引用（&）与指针（*）

## 讲解

这是 Java 开发者最需要先掌握的点。

Java 对照：
- Java 里对象变量本质是“引用语义”，但语言层面隐藏了指针细节。
- C++ 同时有“引用”和“指针”：
  - 引用 `T&`：必须绑定到一个对象，通常不为 `null`
  - 指针 `T*`：可以为空，可以改指向

在 LLVM/MLIR 中常见习惯：
- 参数必须存在：`T&`
- 参数可能缺失：`T*`

## 常见坑

- 野指针/悬空指针（对象生命周期结束后仍在用指针）。
