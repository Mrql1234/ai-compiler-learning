# 05 引用（&）与指针（*）

## 讲解

这是 Java 开发者最需要先掌握的点。

Java 对照：
- Java 里对象变量本质是“引用语义”，但语言层面隐藏了指针细节。
- C++ 同时有“引用”和“指针”：
  - 引用 `T&`：必须绑定到一个对象，通常不为 `null`
  - 指针 `T*`：可以为空，可以改指向

在 LLVM/MLIR 中常见习惯：
- 参数必须存在：`T&`
- 参数可能缺失：`T*`

```
函数参数里有什么区别
指针参数
void inc(int* p) {
    (*p)++;
}
调用时：

int x = 1;
inc(&x);
你必须显式传地址。

引用参数
void inc(int& x) {
    x++;
}
调用时：

int x = 1;
inc(x);
写起来更像按值传递，但实际修改的是原对象。

所以：

指针参数更显式地表达“可能为空 / 可选”
引用参数更适合表达“这里一定要传一个有效对象，而且我要直接操作它”
```

一句话总结
指针是保存地址、可为空、可改指向、需要解引用；引用是对象别名、通常不能为空、不能改绑、用起来像原变量。
