# 06 const（只读约束）

## 讲解

`const` 用来表达“不会修改”。

Java 对照：
- Java 的 `final` 主要限制“变量不能重新赋值”。
- C++ 的 `const` 更强，可作用于变量、引用、指针、成员函数。

常见写法：
- `const T&`：只读引用，避免拷贝且不允许改值。
- `foo() const`：成员函数承诺不修改对象状态。

## 常见坑

- `const int* p` 与 `int* const p` 含义不同：
  - 前者“指向常量的指针”（值不能通过指针改）
  - 后者“常量指针”（指针本身不能改指向）
